# prodagy2026_web

Вебинар «Клиенты, воронки и продажи в 2026 году» — 9 сентября, 17:00 мск.
Отдельный сайт из трёх блоков. Форма регистрации пока является заглушкой.
Подарок за регистрацию: «21 фишка в продажах».
Большой сайт мастер-класса с тарифами хранится отдельно в репозитории prodagy2026.

## Запуск

```bash
pnpm install
pnpm dev
```

Сборка: `pnpm build`. Каталог публикации: `dist`.
