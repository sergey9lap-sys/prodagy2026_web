# RU и COM

Этот проект — COM в папке `agk-webinar-com/` репозитория `sergey9lap-sys/prodagy2026_web`. RU-версия находится в корне репозитория.
Различия задаются в `deployment.json`. HTML подставляет точные script id и widget id при запуске Vite и сборке.

| Проект | Виджет | После успешной регистрации |
|---|---|---|
| RU / исходный | 1655985 | `https://ВАШ-RU-ДОМЕН/spasibo/` |
| COM / agk-webinar-com | 1656005 | `https://agkedu.com/thanks/` |

Сопоставление виджетов пока предварительное, по указанию пользователя.

## Что настроить в GetCourse

В действии формы **после успешной регистрации** установить полный HTTPS URL из таблицы. Если есть выбор, переход должен менять всю страницу, не только iframe. RU-домен ещё не подтверждён. Не использовать событие клика или произвольные postMessage как подтверждение регистрации.

`data-success-path` в HTML — декларация ожидаемого адреса для интегратора, не автоматический редирект. Присланный загрузчик управляет iframe и его высотой, но не предоставляет подтверждённого события успешной регистрации. Работу отправки и редиректа необходимо проверить после настройки GetCourse тестовой регистрацией с согласованными данными. Тестовые заявки агентом не отправлялись.

## Размещение

- COM: импортировать `sergey9lap-sys/prodagy2026_web`, ветка `main`, имя Vercel-проекта `agk-webinar-com`, **Root Directory `agk-webinar-com`**, framework Vite, build `npm run build`, output `dist`. Использовать отдельный Vercel-проект, не перенастраивать RU-проект.
- RU / Beget: собрать `npm run build` и разместить **содержимое dist** в корне сайта. Не загружать исходный index.html — он содержит шаблонные маркеры. Все папки assets, fonts, thanks и spasibo тоже нужны.
- Оба результата сборки содержат `/thanks/` и `/spasibo/`; настройка формы выбирает нужную страницу.
- Форма и обработка персональных данных находятся на стороне GetCourse. Её тексты, согласия, стили и редиректы редактируются там; сайт не имитирует успешную регистрацию.
